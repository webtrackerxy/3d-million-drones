# Google Maps attribution logo

Downloaded 2026-10-28 from the official [attribution asset ZIP](https://developers.google.com/static/maps/documentation/images/Google_Maps_Attribution_Assets.zip). google-maps-logo.png is the unmodified DarkGray_2x.png asset (196 × 36 pixels), embedded at 18 CSS pixels high. logo.json contains its data URL, origin and SHA-256; see also public runtime asset-origins.json.

This is a Google brand asset, not CC0, MIT, Apache-2.0 or ODbL. Use is for the Google imagery attribution described in the [Map Tiles API policies](https://developers.google.com/maps/documentation/tile/policies). It is shown together with visible-tile data-provider credits only while Google 3D is active. Do not imply Google affiliation or apply the logo to the local OSM map.

No Google imagery or tile data has been downloaded into this repository. User credentials are not bundled.
