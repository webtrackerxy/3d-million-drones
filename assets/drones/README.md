# Downloaded drone models

These are unmodified CC0 source candidates, downloaded on 2026-10-26. They are not yet prepared
for instanced rotor animation or the million-drone renderer.

The selected sci-fi model now has a separate [prepared version](prepared/README.md) used by the
first flight runtime. The originals listed below remain unchanged.

| Original file                                               | Author/publisher | Triangles |
| ----------------------------------------------------------- | ---------------- | --------: |
| [scifi-drone.glb](original/scifi-drone.glb)                 | Innerscene       |       360 |
| [quadcopter-original.glb](original/quadcopter-original.glb) | Innerscene       |     5,036 |
| [inspection-drone.glb](original/inspection-drone.glb)       | 3DAssets.dev     |     1,252 |

[sources.json](sources.json) records source/download URLs, publisher licence links, and SHA-256
hashes. [CC0-1.0.txt](licences/CC0-1.0.txt) preserves the CC0 legal text. Publisher pages and
terms were checked for these individual files; no asset from the custom-licence alternative was
downloaded. All source GLBs stay unchanged. Any future converted/merged/LOD version must go in a
separate directory with modification notes.

See test results and the
interactive model lab. The lab embeds the models and
opens directly from disk in a WebGPU browser, without a server or external requests.
